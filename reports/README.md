# Reports

Generated by `./elc test` (not committed):

- `report.json` — summary of the last run: commit, platform, test-suite hash
  and the status of every implementation.
- `evidence/<language>/` — per-language evidence: `manifest.json`,
  `source.sha256`, `environment.json`, `tests.json`, `execution.log`.

CI uploads this directory as a build artifact.
